- **M1 `[Bug/behaviour]` Fishing time windows silently changed** (`WorldSchedule.matchesTimeWindow`, `FishingEngine.eligible`). Old fishing: DAY 0..11999, DAWN_DUSK 12000..13500 + 22500..23999, NIGHT 13501..22499. New (shared with spawns): DAY 1000..11999, NIGHT 13000..22999, DAWN_DUSK <1000 + 12000..12999 + ≥23000. 14 shipped fish species use `time_windows`, so catch tables shift by up to 1000 ticks (50 s) at each boundary (e.g. a DAY-only fish is no longer available at ticks 0..999; a DAWN_DUSK fish becomes available then). A new unit test pins the boundaries, so it is deliberate, but it is a gameplay change that is not in the Task 25 notes. Record it in AGENT_STATUS/release notes and confirm the authored fish windows (dawn_minnow, moon_carp, …) still read right.
