# EtherealChronicle UI・独自Mob・ワールド作り込み 設計書

- **対象バージョン**: Minecraft: Java Edition **26.3** / Paper **26.3** / Java **25** / Kotlin **2.4.21**
- **採用スタック（確定方針）**:
  - **UI**: Paper Dialog API + Adventure / MiniMessage + InvUI v2（MIT・シェード）＋ リソースパック（任意適用・フォールバック両対応）
  - **Mob表示**: プラグイン同梱データパック（`DatapackRegistrar`、`wolf_variant` 等）＋ 3Dボス / 看板NPCは **BetterModel**（MIT・`softdepend` 任意連携、未導入時フォールバック必須）
  - **ワールド**: Paper `StructureManager`（`.nbt` 構造体）＋ `DemoWorld.kt` のハイブリッド方式
  - **リソースパック配布**: 既定＝別ポート内蔵 HTTP（または外部静的ホスト）＋ Adventure `ResourcePackRequest`（SHA-1・Configuration Phase）、同一ポート Netty 注入は実験的オプトイン（既定 OFF）。**コアシェーダは不使用**。
- **関連ソース**: `resourcepack/`（`pack.mcmeta` format `97.1`、完全自作・権利クリーン）、`docs/WORLD_UI_ENGINE_REQUESTS.md`（Codex 実装依頼書）

### 1.2 デュアルモード設計（リソースパック ON / OFF 両対応）

プレイヤーがリソースパックを拒否・未読込・無効化した場合でも**機能差ゼロ・文字化けゼロ**で遊べるよう、全 UI・HUD・Mob を「リソパ ON 表現」と「フォールバック（バニラ）表現」の2層で定義する。

| 要素 | リソパ ON（`hasResourcePack == true`） | リソパ OFF フォールバック（`hasResourcePack == false`） |
|---|---|---|
| **GUI タイトル・背景** | `<font:ec:ui>` 負スペース＋背景グリフ（`U+E100`–`U+E105`）＋白文字タイトル | 通常の MiniMessage 色付きテキストタイトル（例: `<gold>✦ ステータス・装備`）＋ダークグレー板ガラス枠 |
| **GUI ボタン / 空枠** | `minecraft:item_model="ec:ui_btn_*"` / 透明ボタン `ec:ui_transparent` | バニラ標準アイコン（矢印＝`ARROW`、閉じる＝`BARRIER`、確定＝`LIME_DYE`、枠＝`GRAY_STAINED_GLASS_PANE`） |
| **職業紋章 / 伝説装備** | `minecraft:item_model="ec:ui_class_*"` / `ec:wpn_*` / `ec:acc_*` | 既存 YAML の `material`（`NETHERITE_SWORD`, `BOW`, `TRIDENT`, `NETHER_STAR` 等）＋光沢エンチャント |
| **ActionBar HUD** | `<font:ec:hud>` アイコン（`U+E200`–`U+E207`）＋分割バー（`U+E220`–`U+E22E`） | MiniMessage Unicode ゲージ（`❤ 420/500 [████░] ◆ 120/150 [███░]`） |
| **BossBar（エリア/釣り/ボス）** | 属性バッジ（`U+E210`–`U+E215`）＋釣り張力バー | テキストタグ（`[氷]` `[暴走]`）＋既存 `FishingUiFeedback` テキスト |
| **独自Mob** | 同梱 `wolf_variant` テクスチャ / BetterModel 3D | バニラ Mob テクスチャ＋カスタム装備/Scale/パーティクル＋頭上名札 |

> **鉄則**: `U+E000`–`U+E2FF` の私用領域（PUA）文字は **`hasResourcePack == true` のプレイヤーにのみ送信**する。リソパ未適用プレイヤーには一切送らない（豆腐文字 `□` 防止）。また `/ec ui pack [on|off|auto]` で個人ごとに切替可能にする。

### 1.3 画面サイズ・GUI スケール別レスポンシブ基準

| クライアント環境 | 想定解像度 / GUI Scale | 設計上の制約と対策 |
|---|---|---|
| **標準デスクトップ** | 1920×1080 / Scale 3（論理 640×360） | 基準ターゲット。6行チェスト（176×222px）＋ActionBar 46半角幅相当が余裕で収まる |
| **小型ウィンドウ / Scale 4** | 1280×720 / Scale 4（論理 320×180） | 6行チェスト背景が上下端に近づく。**背景グリフは 176×222px の標準コンテナ幅内に厳密収容**し、左右にはみ出すオーバーサイズ装飾を禁止 |
| **ActionBar 折り返し防止** | 全 Scale 共通 | 1行あたり**最大 260px（日本語換算 28〜32文字以内）**に収める。スキルCDは短縮表記（例: `[1]準備 [2]3s`） |
| **BossBar 上限** | 全 Scale 共通 | 同時表示は**最大 2本まで**（1本目: ボス戦HP or 釣りミニゲーム、2本目: エリア帯［任意非表示可］）。3本以上重ねて視界上部を塞がない |
| **Paper Dialog API** | 全 Scale 自動対応 | クライアントがウィンドウ幅に合わせて自動折り返し・スクロールするため、1ページあたり本文 4〜6行・選択肢最大 6個を上限とする |

## 3. 独自 Mob・ボス・看板 NPC 表示一覧（全24体＋主要NPC 8体）

### 3.1 割当方針の3区分

1. **`vanilla variant + テクスチャ`（同梱データパック `DatapackRegistrar`）**: MC 26.3 でデータ駆動バリアントが存在する `WOLF` 系3体に専用テクスチャ（成体 `64×32` + 幼体 `32×32`、wild/tame/angry）を定義。軽量かつ純バニラで確実に反映。
2. **`BetterModel`（MIT・`softdepend` 任意連携）**: 全6体のボス＋森の象徴エリート1体（星蝕トレント）＋看板NPC 8体を Blockbench `.bbmodel` による3Dモデル対象に指定。**BetterModel 未導入環境でも必ずフォールバック（`wolf_variant` / カスタム装備 `item_model` / `SCALE` 属性 / パーティクル）で機能する**。
3. **`そのまま + カスタム装備 / 演出`**: 通常雑魚・人型教団員・精霊系はバニラ骨格を活かしつつ、頭/武器のカスタム `item_model`、防具染色、`GENERIC_SCALE` 属性、属性パーティクルで世界観を統一（TPS・クライアントFPS負荷を極小化）。

### 4.2 構造物 `.nbt` の作成・配置方針（`StructureManager` + `DemoWorld` ハイブリッド）

1. **保存場所・命名規約**:
   - `src/main/resources/structures/ec/<area_short>/<structure_name>.nbt`
   - 例: `structures/ec/lumina/guild_hall.nbt`, `structures/ec/ashwood/ancient_tree_a.nbt`, `structures/ec/glacial/citadel_gate.nbt`
2. **サイズ・パレット規約**:
   - 1 `.nbt` あたり最大 **`32×32×32` ブロック**（バニラ Structure Block 互換。大型建築は `part_west` / `part_east` 等へ分割）。
   - 建築制作はローカル建築サーバー（FAWE/WorldEdit 併用可）で行い、最終的にバニラ `.nbt` として出力し Git 管理する。
   - **禁止ブロック**: コマンドブロック、ジグソー残留、自然増殖して景観を壊すツタ/火（配置時に `BlockTransformer` で安全化）、エンティティ内蔵（NPCやMobはYAML管理のため `.nbt` にエンティティを含めない）。
3. **既存ワールド安全マイグレーション（`v4 → v5` 規約）**:
   - 現行 `DemoWorld.kt` の `.etherealchronicle-owned` / `.etherealchronicle-built` 機構を踏襲。
   - **保護ルール**: 構造体配置時は `BlockTransformer` で「置換対象が `AIR` または自動生成された初期床面（`SMOOTH_STONE`/`GRASS_BLOCK`/`SNOW_BLOCK` 等）のみ設置可、NPC・スポーン・釣り場・宝箱の安全クリアランス領域（半径2m×高さ3m）は空気保持」を保証し、既存プレイヤーの建築物を壊さない。
   - 橋（幅7）と島外周は地形骨格として引き続き `DemoGenerator` が高速生成し、建築物・装飾だけを `StructureManager` が上乗せする。

#### (2) パーティクル・サウンド・昼夜/天候連動（TPS安全設計）

- **パーティクル予算**: プレイヤー単位・半径 24m 以内・20 ticks（1秒）周期で最大 12粒子/回に制限（サーバー全域走査禁止、既存 `EnemyController` の局所設計に準拠）。
  - ランドマーク固有: ルミナ港ランタン火の粉（`FLAME` 微量）、星見の丘天球儀（`END_ROD` 円軌道）、虚核聖堂中央（`PORTAL` 上昇）、氷嶺鍛冶炉（`CAMPFIRE_COSY_SMOKE`）。
- **サウンド演出**:
  - エリア侵入時の短い環境ジングル（ルミナ港: `BLOCK_AMETHYST_BLOCK_CHIME`、廃坑: `AMBIENT_CAVE` 弱音、虚核聖堂: `BLOCK_BEACON_AMBIENT`、蒼氷エリア: `BLOCK_GLASS_CHIME` 相当）をクールダウン 60秒付きで再生。
  - UI操作音: タブ切替 `UI_BUTTON_CLICK`、強化成功 `BLOCK_ANVIL_USE` + `ENTITY_PLAYER_LEVELUP`、購入 `ENTITY_EXPERIENCE_ORB_PICKUP`。
- **昼夜・天候の運用ルール**:
  - 既存の `WorldSchedule`（`night` / `twilight` / `rain` に出現する希少Mob・魚・隠しクエスト：`luna_twilight_catch` や `moonshower_herbalist` 等）を壊さないため、**`ec_world` の昼夜サイクル（`doDaylightCycle=true`）と天候変化（`doWeatherCycle=true`）は維持**する。
  - 視覚フィードバックとして、夕暮れ（`12000–13800`）・夜（`13800–22200`）・雨天時に BossBar 環境枠の星時計アイコンを切替え、プレイヤーが「今が黄昏釣り・雨宿りNPCの時間帯だ」と自然に気付けるようにする。
  - ダンジョンインスタンス内のみ、クライアント側 `Player#setPlayerTime` / `Player#setPlayerWeather`（パケットによる個人視覚上書き）で雰囲気を固定する（`void_sanctum`=深夜固定、`glacial_citadel`=薄暮＋降雪、`novice_arena`=昼晴れ、`aether_crucible`=星空固定）。ワールド全体の時計は一切汚さない。
