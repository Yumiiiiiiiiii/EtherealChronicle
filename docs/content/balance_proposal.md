  $$\text{XP\_to\_next}(L) = \text{round}_{10}\!\left(100 + 45(L - 1) + 18(L - 1)^2\right)$$

### クエストXP収支のサニティチェック
- **メインクエスト8本合計**: `19,530 XP`（Lv18累計 `34,750` の **56.2%**）
- **単発サイドクエスト9本合計（分岐A/Bいずれか）**: `12,210 XP`（累計 **31,740 XP** = Lv18の **91.3%**）
- **クエスト道中の必須討伐XP（目安）**: 約 `5,500〜7,500 XP`（ボス初撃破含む）
- **合計**: 単発クエスト完走＋道中討伐で **37,240〜39,240 XP** → ラスボス到達時に自然に **Lv17〜18**、撃破報酬で **Lv18〜19** に到達！
- 残り約 `8,500〜10,000 XP`（Lv20到達まで）は反復クエスト `ec:quest_s11_cult_purge`（2,400 XP）や `ec:quest_s12_sanctum_trial`（3,800 XP＋ボス3,200 XP）を2〜3回こなせば到達でき、過剰な雑魚狩り（苦行）を要求しない。
- **レベル差XP減衰**: プレイヤーLv − 敵Lv が `+4` 以上で1Lvごとに `-20%`（最低10%）、格上補正は最大 `+15%`（パワーレベリング防止）。

#### ラスボス「ヴォイド・ウォーデン」協力戦タイム検算
- **1人挑戦** (`HP 34,000`, `ATK 115`, `DEF 85`):
  - 平均DPS約 `215` × ギミック回避による実稼働率 `65%` ＝ 有効DPS `140` → `34,000 / 140 ≈ 243秒`（**約4分＋フェーズ演出1分＝約5分**）。
- **4人パーティ** (`HP 110,500`, `ATK 129`, `DEF 85` — 構成例: 戦1・弓2・魔1):
  - 合計DPS約 `860`（バフ・デバフ込み） × 稼働率 `62%` ＝ 有効DPS `533` → `110,500 / 533 ≈ 207秒`（プリズム破壊・フェーズ遷移込みで **約5〜6分**）。
  - 戦士の通常被ダメ: `129 × (100 / 262) = 49.2`（HP940に対し約19発）、タンクバスター(2.1x)は防御スキル軽減込みで `~75〜105` → ヒーラー/回復薬で安定維持可能。
  - 弓・魔のテレグラフ強撃直撃: `129 × 2.4 × (100 / 195) = 159`（HPの約25〜28%）→ 1発で即死しないが、回避を怠り2連続で受けると致命的という健全な緊張感！

- 攻撃系: `ATK` (+3〜16), `CRIT%` (+1〜4%), `CRIT_DMG` (+4〜12%), `SKILL_POWER` (+6〜24)

## 4. ゴールド経済収支（Gold In / Out）検算

レベル帯ごとのプレイヤー1人あたり平均収支モデル。**「必要装備と消耗品は無理なく買えるが、全買いや無計画な浪費はできず、素材売却・反復クエスト・選択分岐に価値が残る」** バランスを目指す。

### 収入（Gold In）と支出（Gold Out）対照表
| レベル帯 | クエスト収入 | 討伐＋素材売却収入 | **収入合計** | 推奨装備購入 | 消耗品・料理・巻物 | **支出合計** | **帯域純残高** |
|---|---|---|---|---|---|---|---|
| **Lv1〜5**（森前半） | `620G` | `480G` | **1,100G** | 兜/オフハンド/Lv5武器はクエスト補完込みで約 `450G` | 回復薬×10, シチュー×3, 巻物×2 = `485G` | **935G** | `+165G` |
| **Lv6〜10**（森後半〜廃坑前半） | `1,400G` | `1,350G` | **2,750G** | 軽足具/補強脚甲/サブ強化 `1,020G` | 中級薬×10, 解毒×4, 焼肉×3, 巻物×3 = `1,505G` | **2,525G** | `+225G` |
| **Lv11〜15**（廃坑後半〜星見前半） | `3,100G`〜`3,710G` | `2,200G` | **5,300G**〜`5,910G` | Lv11レア武器+オフハンド（片方ドロップ補完） `1,250〜2,350G` | 中/上級薬, ハーブティー, 星羽×2 = `1,950G` | **3,200〜4,300G** | `+1,600G` |
| **Lv16〜20**（星見後半〜聖堂） | `3,090G`（+反復） | `2,500G`（聖堂2-3周） | **5,590G+** | エピック胸鎧補完/聖堂準備品 `2,200G` | 上級薬×10, 星羽×3, ティー×4 = `4,000G` | **6,200G** | 余剰残高で黒字維持 |
| **第1章通し累計** | **`8,210G`〜`8,820G`** | **`6,530G`** | **`14,740G`〜`15,350G`** | **`4,920G`〜`6,020G`** | **`7,940G`** | **`12,860G`〜`13,960G`** | **`+1,400〜+1,900G`（第2章資金）** |

- **経済の健全性チェック**:
  - 序盤（Lv1–5）で資金ショートしない（残高+165G）。
  - 中盤（Lv11–15）でガルド／トマスからレア装備を買う明確な動機がある。選択1の10%割引や選択2Bの+350Gが実感できるインパクトを持つ。
  - 売却レートを全店一律 `0.30x`（割引買値 `0.90x` 未満）に固定しているため、ショップ転売による無限Gold増殖は不可能。

## 6. 安全キャップ・アンチチート数値上限（`balance.yml` 規定推奨値）

`AGENTS.md` の「XP/currency gains capped by balance config」および戦闘破綻防止のためのシステム上限案。

| パラメータキー | 推奨上限値 | 目的 |
|---|---|---|
| `max_level` | `20` | v1.0レベルキャップ |
| `max_crit_chance` | `65.0%` | 確定会心ループの防止（特定スキル効果のみ例外可） |
| `max_crit_damage_mult` | `2.50` | 会心ダメージ乗算の暴走防止 |
| `max_element_res` | `50.0%` | 属性ダメージ完全無効化の防止 |
| `def_soft_cap_curve` | `100 / (100 + DEF)`（最大軽減 `75%` = DEF `300` 上限） | 無敵タンク化の防止 |
| `max_single_hit_damage` | `2,500`（v1.0環境） | 計算バグ・スキル重複によるボス一撃死防止 |
| `max_xp_per_minute` | `4,500`（クエスト完了報酬は別枠） | スポナー放置・無限湧き悪用防止 |
| `max_gold_per_minute` | `1,200G`（クエスト・ショップ売却は別枠） | ボット狩りによる経済崩壊防止 |
| `party_xp_share_radius` | `40` ブロック（ボーナス：2人 `+5%`, 3人 `+10%`, 4人 `+15%` を分配） | パーティ協力プレイの推奨＋放置吸い取り防止 |
| `dungeon_max_players` | `4` | 虚核の聖堂のTPS・バランス保護 |
