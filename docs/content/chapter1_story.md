## 1. 世界観・プロローグ設定

### 浮遊大陸「アエリア（Aelia）」
雲海の上に浮かぶ大小無数の浮島群――それが人々の暮らす大地「アエリア」である。
かつてこの空は、中央聖域に鎮座する巨大な結晶体 **〈エーテル核（Aether Core）〉** の重力制御と魔力循環によって平穏に保たれていた。

しかし **千年前**、原因不明の「大崩落」によって〈エーテル核〉は砕け散り、無数の欠片 **〈星片（Starshards）〉** が各地の浮島へと降り注いだ。
〈星片〉は大地に豊かな魔力資源と飛空艇技術をもたらした一方で、その過剰なエーテル波動に触れた野生生物や古の遺物は変質し、凶暴な **魔物** へと変貌した。

そして現代。辺境の浮島にある港町 **「ルミナ港」** の近郊で、千年間眠っていた星片の一つが突如として不安定な共鳴を始めた。
森の獣たちは理性を失い、廃坑の奥からは黒き瘴気が漏れ出している。その背後では、砕けた星片を再び集め「虚無の核」を創り上げようと画策する秘密結社 **黒き教団〈虚ろの手〉** が暗躍していた――。

### 第1幕：導入 — 蒼穹の港町での目覚め (`ec:beat_ch1_intro`)
- **あらすじ**: 定期飛空艇から降り立った見習い冒険者（プレイヤー）は、白い石畳と風車が回る港町 **ルミナ港** で新たな一歩を踏み出す。受付嬢 **セリア** に迎えられ、冒険者ギルド本部でギルド長 **ヴァルカン** と面会。自身の戦闘適性を見極め、**戦士 (`ec:class_warrior`)**・**弓使い (`ec:class_archer`)**・**魔法使い (`ec:class_mage`)** のいずれかを選ぶ。鍛冶屋 **ガルド** から初期武装を受け取った矢先、町の外れから甲高い鐘の音が鳴り響く。
- **演出ポイント**: ホットバー9番のスキルスロット操作（`F` キーでスキル切替・右クリック発動・しゃがみ＋右クリック）のチュートリアルを自然に組み込む。

### 第2幕：事件 — アッシュウッドの森の異変 (`ec:beat_ch1_incident`)
- **あらすじ**: ルミナ港に隣接する **アッシュウッドの森** で、温厚だったスライムや狼が突如として凶暴化し、街道の行商人が襲われた。前哨キャンプを守るレンジャー隊長 **エレナ** の指揮のもと魔物を押し返したプレイヤーは、森の最奥で紫蒼の光を放ち暴走する **〈暴走した森の星片〉** と、それに取り憑かれた巨木 **星蝕トレント** を撃破する。
- **転換点（重大選択1）**: 鎮まった星片を「森の大地へ還して浄化するか（エレナ案）」「魔導容器に封印抽出してギルド戦力とするか（ヴァルカン案）」をプレイヤーが決断する。どちらを選んでも、星片の周囲には **〈虚ろの手〉の紋章が刻まれた黒い楔** が打ち込まれていたことが発覚し、異変が人為的であったことが明らかになる。

### 第3幕：探索 — 嘆きの廃坑と消えた鉱夫たち (`ec:beat_ch1_exploration`)
- **あらすじ**: 森の楔と同種の魔力反応が、北東の閉鎖鉱山 **嘆きの廃坑** から検出される。野営地で補給官 **トマス** と、どこか歯切れの悪い鉱夫長 **ダレン** から事情を聴取。坑道奥へ潜入したプレイヤーは、星片の鉱脈を掘り起こす **黒き教団〈虚ろの手〉** の信徒たちと遭遇し、密書を奪取する。
- **転換点（重大選択2）**: 密書には「第3縦坑の封印鍵を差し出した協力者・ダレン」の名が記されていた。問い詰めると、ダレンは生き残った部下を教団に人質に取られていたと告白する。プレイヤーは「ダレンを許し贖罪の機会を与えて共闘するか」「規律に従いギルドへ厳正に告発するか」を選択する。

### 第4幕：対立 — 暴走巨兵と星見の丘の対峙 (`ec:beat_ch1_conflict`)
- **あらすじ**: 第3縦坑の最深部で教団が星片を注ぎ込み起動させた古代採掘機械 **「アイアン・グラインダー」**（中ボス）を撃破。しかし教団幹部 **カイン** はすでに本命の星片を奪い、高台の古代遺跡 **星見の丘** へと逃亡していた。
- 丘の天文台跡で待つ **星見の賢者リラ** と合流したプレイヤーは、カインが千年前から封じられていた **「虚核の聖堂」** の封印を解こうとしていることを知る。襲い来る教団狂信者と虚空の魔物を退け、古のアストロラーベを再起動したプレイヤーは、カインの眼前に立ち塞がる。カインは冷笑を浮かべ、聖堂の奥へ姿を消す。

### 第5幕：クライマックス — 虚核の聖堂・協力戦 (`ec:beat_ch1_climax`)
- **あらすじ**: 仲間（パーティー最大4人、ソロ可変スケール対応）と共に、浮島の地下深くへ続く協力ダンジョン **「虚核の聖堂」** へ突入。最奥の祭壇では、カインが奪った星片を虚無の器へ注ぎ込み、古の防衛機構を歪めた怪物 **「虚核の守護者ヴォイド・ウォーデン」** を覚醒させていた。
- **決戦**: 3段階に変化する強大な攻撃（重力波、星片プリズム共鳴、虚空鎖、崩界の審判）を、回避・ヘイト管理・ギミック協力で乗り越え、ついに守護者を打ち倒す。

### 第6幕：エンディング＆第2章への伏線 (`ec:beat_ch1_ending`)
- **あらすじ**: 守護者が砕け散った後、空間の裂け目から再び現れたカインは敗北を悔いるどころか、満足げに微笑む。
  > 「見事です、ルミナの新星よ。ですが……この聖堂の核は、あくまで『第一の鍵』に過ぎません。我が主はすでに **〈第二の星片〉**――北の果て、**〈蒼穹の氷嶺〉** に眠る蒼き核へと手を伸ばしているのです。次に相まみえる時、空はもう墜ち始めているでしょう。」
- カインは虚空の門へ消え去り、祭壇には純化された **〈虚核の残滓〉** が残される。
- **転換点（重大選択3）**: プレイヤーは〈虚核の残滓〉を「ルミナ港ギルドの防衛結界として封印するか」「星見の賢者リラに託して〈第二の星片〉の所在を解析させるか」を決定する。
- ルミナ港に戻ったプレイヤーは英雄として迎えられ、街の風景（ヴァルカン・セリア・リラらの台詞）が変化。第2章「凍てつく蒼穹の星片」への旅立ちの予感を残して第1章が幕を閉じる。

## 5. エリア詳細ガイド（全5エリア）

各エリアは座標アンカー（ワールド構築時の設計目安）と環境演出、生息敵・配置NPCを明記する。

### 1. ルミナ港 (`ec:area_lumina_port`)
- **種別 / 推奨レベル**: 街・安全地帯（PvP無効・自然回復加速） / `Lv1〜`
- **景観・雰囲気**: 雲海に面した浮島の南端に築かれた白い石造りの港町。大型飛空艇が発着する木造桟橋、青空に回るエーテル風車、活気ある市場通り、中央にそびえる冒険者ギルド本部が特徴。BGM/環境音は穏やかな風と港の鐘。
- **主要ランドマーク**:
  - **飛空艇桟橋**（初期スポーン地点・行商人ピップ）

### 2. アッシュウッドの森 (`ec:area_ashwood_forest`)
- **種別 / 推奨レベル**: オープンフィールド / `Lv1〜8`

- **サブゾーン**:
  - **南の街道・木漏れ日広場** (Lv1–4)：`ec:enemy_aether_slime`, `ec:enemy_thorn_wolf`, `ec:enemy_moss_goblin`

  - **胞子の湿原** (Lv5–7)：`ec:enemy_spore_spider`, `ec:enemy_moss_goblin`
  - **星片の古樹広場** (Lv7–8)：エリート `ec:enemy_corrupted_treant`・暴走した森の星片祭壇
- **接続**: 南→ルミナ港、北東→嘆きの廃坑

### 3. 嘆きの廃坑 (`ec:area_weeping_mine`)
- **種別 / 推奨レベル**: フィールド＆半屋内ダンジョン構造 / `Lv8〜14`
- **景観・雰囲気**: かつて良質なエーテル鉱石を産出した大鉱山。十年前の落盤事故で閉鎖されたが、坑道を吹き抜ける風がすすり泣くように響くことから「嘆きの廃坑」と呼ばれる。奥へ進むほど黒い教団の篝火と紫の結晶が増える。
- **サブゾーン**:

  - **第1・第2水平坑道** (Lv8–11)：`ec:enemy_mine_kobold`, `ec:enemy_crystal_bat`, `ec:enemy_obsidian_golem`

  - **隠し縦坑**（選択2A解放）：`ec:quest_s08_daren_atonement` 舞台
- **接続**: 南西→アッシュウッドの森、北の昇降路→星見の丘

### 4. 星見の丘 (`ec:area_stargazer_hill`)
- **種別 / 推奨レベル**: 高地フィールド / `Lv12〜16`
- **景観・雰囲気**: 廃坑の上層を抜けた先に広がる、雲海を一望できる高台の草原と古代天文台の廃墟。昼は澄んだ蒼空と浮島の連なりが見渡せ、夜は星片の残光が草むらに蛍のように浮かび上がる。古代の石碑群と破損した巨大なアストロラーベが鎮座する。
- **サブゾーン**:

- **接続**: 南→嘆きの廃坑、祭壇ゲート→虚核の聖堂

### 5. 虚核の聖堂 (`ec:area_void_sanctum`)
- **種別 / 推奨レベル**: インスタンス協力ダンジョン（1〜4人、推奨2〜4人・ソロ補正対応） / `Lv15〜20`
- **景観・雰囲気**: 星見の丘の地下に封じられていた千年前のエーテル貯蔵聖堂。黒曜石と白大理石が幾何学的に組み合わされた神殿内部には、砕けた星片が宙に浮かび、重力場が微かに歪んでいる。
- **区画構成**:
  1. **第1区画：星光の回廊** — `ec:enemy_void_sentinel` と `ec:enemy_cult_zealot` の混成部隊を撃破し、2基の共鳴柱を起動して門を開く。
  2. **第2区画：虚空の橋** — 定期的に虚空波が走る石橋を渡りながら、星片の楔を破壊してバリアを解除するギミック区画。
  3. **最奥：虚核の祭壇** — ラスボス **「虚核の守護者ヴォイド・ウォーデン」** (`ec:boss_void_warden`) との3フェーズ決戦アリーナ（半径約24ブロックの円形闘技場＋外周に4基の星片プリズム台座）。
- **クリア後演出**: 祭壇中央に宝箱（個人ドロップ判定）と脱出ポータルが出現。初回クリア時はカインの撤退イベントと選択3が発生する。
