# 第1章 敵・ボス設計バイブル (`ec:enemy_*`, `ec:boss_*`)

> **概要（YAML変換用データ設計）**
> - **通常・エリート敵**: 全 **14種**（アッシュウッドの森5 / 嘆きの廃坑5 / 星見の丘3 / 虚核の聖堂1）
> - **ボス**: 全 **2体**（中ボス「アイアン・グラインダー」Lv12 / ラスボス「虚核の守護者ヴォイド・ウォーデン」Lv18・協力戦対応）
> - **属性相性ルール**（`elementMod`）:
>   - 弱点属性攻撃: `1.25x`
>   - 耐性属性攻撃: `0.80x`
>   - 通常属性: `1.00x`
>   - 属性体系: `PHYSICAL` / `FIRE` / `ICE` / `LIGHTNING` / `AETHER` / `VOID`（`AETHER` と `VOID` は相互弱点 `1.25x`）
> - **ダメージ計算式**（`docs/GAME_DESIGN.md` 準拠）:
>   `dmg = (ATK * skillMult + weapon) * (100 / (100 + DEF)) * crit * elementMod`

#### フェーズ遷移と行動パターン
- **フェーズ1：稼働（HP 100% → 50%）**
  - **【ドリル突進】**（予兆1.5秒・直線幅3m×14mの赤パーティクル床＋警告音 `ENTITY_RAVAGER_ROAR`）— 高速直進（`ATK × 1.9`＋ノックバック）。横移動で完全回避。壁に激突させると2.5秒間「過熱硬直」（被ダメージ `+20%`）。
